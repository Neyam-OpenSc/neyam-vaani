Roadmap

Ten phases to a public beta.

The plan is public, in order, and deliberately narrow: a voice assistant that does twenty things excellently, in nine languages, on the cheapest phone in the house. Updated as phases complete.

  • Phase 0

    Bootstrap

    Repository, charters, documentation, app skeleton, continuous integration — the project's foundation.

    In progress
  • Phase 1

    Voice input

    Whisper bridge, push-to-talk, streaming transcription and language detection in the first three languages.

    Planned
  • Phase 2

    Voice output

    Piper neural voices for nine languages: calm pacing, instant interruption, adjustable speed.

    Planned
  • Phase 3

    On-device language model

    Qwen 2.5 via llama.cpp: streamed answers, cancellable generation, graceful behaviour under memory pressure.

    Planned
  • Phase 4

    Intent and orchestration

    The twenty core use cases classified on-device in under 200ms, with the model as fallback.

    Planned
  • Phase 5

    Actions

    Messages, calls, reminders, clipboard, torch — each with just-in-time permissions explained in the user's language.

    Planned
  • Phase 6

    Knowledge base

    Offline answers from a local Wikipedia-derived and government-scheme base, retrieved and spoken without internet.

    Planned
  • Phase 7

    Document reading

    Photograph a letter, form or medicine label; hear it read aloud and explained in plain language.

    Planned
  • Phase 8

    Translation

    On-device NLLB translation between all nine languages, including a two-speaker conversation mode.

    Planned
  • Phase 9

    Polish and beta

    Accessibility and tenderness audits, performance on real low-end devices, then public beta.

    Planned

What v1 will not do

Smart-home control, third-party app integrations, web browsing, image generation, multi-user accounts, iOS and desktop are all out of scope until the public beta ships. This is how twenty use cases get done well instead of two hundred done thinly.

Follow along

Progress is tracked in docs/roadmap.md and in the repository's issues and releases. Watch the repository to know the moment the beta opens.
