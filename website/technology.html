Technology

A complete AI stack, inside a $200 phone.

Vaani assembles proven open components — Whisper, Qwen 2.5, Piper, NLLB — into a pipeline that fits in 2GB of RAM. Every stage runs on the device; no server is involved at any point.

The pipeline

  1. Speech recognition

    Whisper (via whisper.cpp) transcribes speech and detects which of the nine languages is being spoken; Silero voice-activity detection knows when you have finished. Audio is processed in memory and never written to storage.

  2. Understanding

    A fast on-device classifier routes the request to the right handler in under 200ms. Qwen 2.5 — a multilingual model small enough for a phone, running via llama.cpp — handles questions, drafting and explanation, streaming its answer as it generates.

  3. Knowledge and action

    Factual questions draw on a local knowledge base (Wikipedia-derived content, government scheme information) using hybrid full-text and semantic search. Requests that do something — send, call, remind — are carried out through standard Android actions, with your confirmation.

  4. Speech output

    Piper neural voices speak the reply in your language, at a calm default pace, and stop instantly when you begin talking again.

The memory budget

The hard constraint. Everything below runs on a 2GB-RAM phone — the larger model swaps with the speech models rather than co-residing, which is why the orchestration layer exists.

Total, one language~2.4GB~3.5GB peak

Phones with more RAM load the larger model; phones with less load the 1.5B variant automatically. Language packs (~600–900MB each) install on demand, so the app download stays under 80MB. The full specification, including per-language pack contents and signing, is in docs/architecture.md and docs/language-pack-spec.md.

What about the cloud?

Nothing. There is no server, no API key, no account. The only network traffic the app can ever generate is an explicit, opt-in language-pack download, verified by signature before install. This is not a configuration default — it is the architecture.
