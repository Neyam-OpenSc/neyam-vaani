Privacy

Private by architecture, not by policy.

The user is the only person who ever sees their data. There is no cloud to send it to, no account to tie it to, and no telemetry system to feed. This is immutable: no feature, sponsor or roadmap item may violate it, and any contribution that conflicts with it is rejected.

The never list

Advertising, in any form, ever. Selling or sharing user data — there is none to sell. Telemetry, crash reporting or analytics, not even "anonymized". Accounts or sign-ins. Cloud AI calls. Any dependency that phones home.

Permissions

Each permission is requested only when a specific action needs it, with a one-sentence explanation in your language: the microphone is requested "to hear you"; SMS, "to send the message you asked for". Nothing is requested at install time, and nothing is requested twice.

How this is enforced

Every release is audited with a network monitor — zero unexpected traffic. Every new dependency documents its network behaviour in review. The only traffic the app can ever generate is an explicit, opt-in, signature-verified language-pack download over TLS.

The complete charter, including the security implementation (SQLCipher encryption, Android Keystore key storage, signed packs), lives in PRIVACY_CHARTER.md in the repository.
