Questions

Direct answers.

The questions people actually ask, answered the way Vaani itself answers: briefly, plainly, and without hedging.

What is Neyam Vaani?

A free, open source, voice-first AI assistant for Android that runs entirely offline on low-cost phones and speaks nine Indian languages — Tamil, Hindi, Bengali, Kannada, Telugu, Marathi, Bhojpuri, Maithili and English. You speak to it; it speaks back.

Does it really work without internet?

Yes — 100% of core features are offline. Speech recognition, the language model, translation and text-to-speech all run on the phone. The only network use is optional, opt-in language pack downloads.

What does it cost?

Nothing, ever. Apache-2.0 open source. No ads, no accounts, no premium tier — these are permanent product decisions written into the project charter.

Which languages are supported?

Nine, at full parity — including Bhojpuri and Maithili, which commercial assistants skip. Each language ships as a downloadable pack reviewed by a native-speaker steward. See Languages.

Which phones are supported?

Android phones with as little as 2GB RAM (e.g., Redmi 9A). The app auto-selects smaller AI models on low-RAM devices and keeps its download under 80MB.

What happens to my voice data?

Voice exists in memory only and is never stored. Conversation text is encrypted on-device (SQLCipher) and deletable at any time. Nothing is ever uploaded — there is no server to upload to. See Privacy.

Who is building this?

Neyam OpenSc, an open source organization — with native-speaker language stewards owning quality for each language.

When can I try it?

The project is in Phase 0 of a 90-day roadmap to public beta. Follow the repository for releases.
