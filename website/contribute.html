Contribute

The most valuable contribution is a native speaker's ear.

Code matters, but what makes Vaani work in Tamil or Maithili is people who live in those languages. Whatever your skill, there is a first step below — and the community is kind to newcomers by policy.

  1. Language steward

    A native speaker who owns quality for one language: UI strings, prompts, voice naturalness, recognition accuracy on real utterances. Stewards hold merge authority over their language. This is the project's scarcest resource.

  2. Engineering

    Dart/Flutter for the app, C++ for the native bridges (whisper, llama, piper), Python for the knowledge-base pipelines. Clean architecture, tests first for domain logic.

  3. Testing on real phones

    Especially low-end Android devices (2–4GB RAM). Bug reports that name the phone model are gold; the issue templates make it easy.

  4. Knowledge curation

    Wikipedia dumps, government scheme information, form templates, health basics — public-domain sources, documented and cited.

  5. Documentation and translation

    The site you are reading, READMEs, error messages, and their translation into the nine languages.

First steps

Read the Principles and Privacy pages — every contribution is checked against them. Then look for issues labeled good first issue in the repository, or open a discussion and say hello. If you want to steward a language, say so in the discussions — no code required.

The complete process — code style, PR checklist, the settled decisions that are not open for debate (no cloud AI, no telemetry, no gamification) — is in the contributing guide.

Be kind. Be curious. Ship good things.
